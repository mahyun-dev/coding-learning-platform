# 코딩 학습 플랫폼 (Coding Learning Platform)

PHP 기반의 교육용 웹 플랫폼입니다.

## 프로젝트 개요

이 프로젝트는 한국어 사용자를 위한 코딩 교육 플랫폼입니다. 학생들이 프로그래밍 문제를 풀고, 제출하며, 진행 상황을 추적할 수 있는 완전한 웹 기반 학습 환경을 제공합니다.

## 주요 기능

- 사용자 인증 (로그인/회원가입)
- 프로그래밍 문제 목록 및 상세 보기
- 코드 제출 및 자동 채점
- 학습 진도 대시보드
- 관리자 패널

## 기술 스택

- **백엔드**: PHP
- **프론트엔드**: HTML, CSS, JavaScript
- **데이터베이스**: MySQL/MariaDB
